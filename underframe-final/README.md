27основных и17дополнительных геометрических проверок. Это компоновка для обсуждения с прорабом, а не расчёт прочности. До резки и закупки замены метизов требуется сухая примерка реальных деталей.

В каталоге только статические исходники просмотра, ведомость и проверенные иллюстрации. Для локального просмотра достаточно любого статического HTTP-сервера. Текстуры иThree.js локальные.
